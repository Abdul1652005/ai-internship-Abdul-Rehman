# Task 09 - Support Vector Machines and k-Nearest Neighbors

This task compares SVM and kNN classifiers on the Titanic passenger-survival dataset.

## Workflow

- Selected survival as the binary target and engineered `family_size`.
- Imputed missing values, encoded categorical columns, and standardized features for distance- and margin-based models.
- Used an 80/20 stratified train-test split.
- Trained and evaluated SVM and kNN models using accuracy, precision, recall, F1-score, confusion matrices, and ROC curves.

The notebook contains the implementation and the PDF contains the completed analysis.
