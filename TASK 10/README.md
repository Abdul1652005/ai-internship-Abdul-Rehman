# Task 10 - Cross-Validation and Hyperparameter Tuning

This task improves a Random Forest classifier for Titanic survival prediction.

## Workflow

- Built a leakage-safe preprocessing pipeline with imputation, one-hot encoding, and feature scaling.
- Used stratified train/test splitting and cross-validation, including K-Fold and Stratified K-Fold methods.
- Tuned model parameters with both `GridSearchCV` and `RandomizedSearchCV`.
- Compared baseline and tuned models using accuracy, precision, recall, F1-score, and confusion matrices.

The notebook and formatted report document the experiments and comparison.
