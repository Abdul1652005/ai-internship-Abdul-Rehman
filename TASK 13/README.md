# Task 13 - Advanced Model Evaluation and Imbalanced Data

This task uses the Wisconsin Breast Cancer Diagnostic dataset for binary classification.

## Topics covered

- ROC curves and ROC-AUC evaluation.
- Learning curves and interpretation of generalization.
- A realistic class imbalance created by reducing the malignant class.
- Logistic Regression baseline evaluation with precision, recall, F1-score, and confusion matrices.
- Imbalance-handling methods including SMOTE and class weighting.

The notebook and report document the experiments and their results.
