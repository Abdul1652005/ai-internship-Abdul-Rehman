# Task 11 - Comparative Analysis of Classification Models

This task fairly compares Logistic Regression, Random Forest, and SVM on the Titanic dataset.

The workflow uses the same stratified train/test split for all models, handles missing values, encodes categorical features, and standardizes features where appropriate. Results are compared with accuracy, precision, recall, and F1-score; the report shows Random Forest achieving the strongest overall result among the tested models.
