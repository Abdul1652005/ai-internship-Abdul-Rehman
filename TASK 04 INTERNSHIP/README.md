# Task 04 - NumPy and Pandas for Data Analysis

This task develops practical skills for numerical computing and tabular data analysis in Python.

## Topics covered

- Creating one- and multi-dimensional arrays with `array`, `zeros`, `ones`, `eye`, `arange`, `linspace`, and random values.
- NumPy indexing, slicing, reshaping, mathematical operations, broadcasting, vectorization, dot products, matrix multiplication, transpose, and inverse.
- Pandas Series and DataFrames, filtering, sorting, `groupby`, merging, and joining.
- A Titanic mini-project that cleans missing Age, Embarked, and Cabin values and analyzes survival by gender and passenger class.

See `Task_04_NumPy_Pandas_Report.pdf` for the completed report.
