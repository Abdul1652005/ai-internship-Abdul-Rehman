# Task 16 - End-to-End Machine Learning Pipeline

This task builds a complete Telco Customer Churn prediction pipeline.

The project covers data cleaning, exploratory analysis, feature engineering, pipeline-based preprocessing, multi-model training, model comparison, hyperparameter tuning, evaluation, and model persistence. The dataset contains 7,043 customers and uses `Churn` as an imbalanced binary target.

The completed report is included in this folder.
