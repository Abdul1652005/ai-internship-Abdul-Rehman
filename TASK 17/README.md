# Task 17 - Neural Networks from Scratch

This task builds neural-network foundations using NumPy rather than a deep-learning framework.

## Topics covered

- A single-layer perceptron trained on linearly separable Iris classes, including decision-boundary evolution and the XOR limitation.
- Step, sigmoid, tanh, and ReLU activation functions.
- A forward- and backpropagation mini-project with a scratch multilayer perceptron on the Wine dataset.
- Comparison with a scikit-learn baseline, evaluation metrics, and model persistence.

The notebook, trained model, and report are included.
