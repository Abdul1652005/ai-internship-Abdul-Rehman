# Task 15 - Model Persistence Mini-Project

This task demonstrates saving and loading trained machine-learning models with Pickle and Joblib.

## What was completed

- Trained a StandardScaler plus Logistic Regression pipeline on the Breast Cancer Wisconsin dataset.
- Saved the model as both `.pkl` and `.joblib` files.
- Loaded both files and verified that their predictions match the original model.
- Completed an end-to-end mini-project covering EDA, preprocessing, model training, evaluation, and final persistence.

The notebook, report, and serialized model artifacts are included.
