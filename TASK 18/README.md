# Task 18 - Introduction to PyTorch

This task introduces PyTorch tensors, autograd, and the `nn.Module` API using the Breast Cancer Wisconsin dataset.

It demonstrates tensor creation and reshaping, broadcasting, NumPy/PyTorch memory sharing, automatic differentiation, manual-gradient verification, and a feed-forward neural network with one hidden layer. The network is trained with CrossEntropyLoss and Adam using a standard PyTorch training loop.
