# Task 02 - Python Fundamentals

This task covers core Python programming and introductory AI development concepts.

## Topics covered

- Built-in data types, user-defined functions, comprehensions, classes, objects, and inheritance.
- Text-file writing, appending, and reading.
- Exception handling for invalid input and division-by-zero cases.
- Reading student data from CSV and JSON files.
- Virtual environments, Conda environments, and dependency isolation.
- Definitions of AI, machine learning, deep learning, and supervised, unsupervised, and reinforcement learning.

The Python solutions and sample files are accompanied by the submitted task reports.
